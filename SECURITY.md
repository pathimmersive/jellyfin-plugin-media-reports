# Security policy

## Supported versions

Only the latest release receives security fixes. The plugin supports Jellyfin 12.0 and later 12.x.

## Reporting a vulnerability

Please report it privately through a [confidential issue](https://gitlab.com/path-immersive/open-source/jellyfin/jellyfin-plugin-media-reports/-/issues/new?issue[confidential]=true) on this project. Only you and the project maintainers can read it. Do not open a public issue or merge request for a vulnerability.

Include:

- what an attacker can do, and what access they need (anonymous, signed-in user, admin);
- the plugin and Jellyfin versions affected;
- steps to reproduce, or a proof of concept.

This is a volunteer project. Reports are acknowledged as soon as a maintainer sees them, and a fix is released before the details are made public.

Vulnerabilities in Jellyfin itself belong to the [Jellyfin project](https://github.com/jellyfin/jellyfin/security), not here.
